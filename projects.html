Projects:

  • Snake Game:

    • I Coded a snake game by integrating and utilizing a graphics module. The game takes inputs from the keyboard, so the player can control the snake’s movements using the arrow keys. The snake is segmented into square components, which move from the tail to the head of the snake in the chosen direction of movement, making the movement look more natural. The high score is saved in an external text file, so the player can track their progress in the game

  • Simple Dictionary Program:

    • I Created a dictionary program that is completely customizable. The user can view, add, and delete words in the dictionary. If the program is terminated then re-run, all changes made to the dictionary will be saved in a separate text file
